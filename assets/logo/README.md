# Logo

Pune aici fișierele oficiale de logo Wood Expert. Tema le caută în această ordine:

- fundal deschis: `logo.svg`, `logo.png`, `logo.webp`, `logo-principal.svg`, `logo-principal.png`
- fundal închis: `logo-negativ.svg`, `logo-negativ.png`, `logo-alb.svg`, `logo-alb.png`

Reguli: nu se deformează, nu se recolorează, nu se reconstruiește cu font. Sloganul „Limitless technology” nu se traduce.
Cât timp folderul e gol, header-ul și footer-ul afișează un spațiu rezervat cu textul „Logo lipsă”.
